# DataCard readability and chat reliability

Goal: every DataCard variant answers the question it was asked and reads calmly at chat width, and the chat around it stays reliable (no hang, short titles, bounded history, honest recall). Proof comes from simulated-user chat rounds in `docs/issues/ai-answers.md` and the card rules in `docs/plans/card-fit.md`, not from `bun run eval` (recordings are stale; live eval is not used). Work lives on branch `datacard-readability` (worktree `.claude/worktrees/datacard-readability`); Studio wiring is on `studio-wiring`.
