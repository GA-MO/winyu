# Run sheet: เดโม Winyu แบบหลายจอ

เรื่องเดียว 4 คน: ยอดขายเข้าภาคอีสานจะหลุดเป้า CEO ส่งเรื่องให้ผู้จัดการขายภาค ผู้จัดการภาคส่งต่อให้พนักงานขาย พนักงานขายรับ แล้วฝ่ายไอทีเห็นว่าใครส่งอะไรให้ใครและใครอนุมัติ ทุกขั้นที่กดบนการ์ดไม่เรียกโมเดลเลย

ถ้อยคำบนจอในเอกสารนี้มาจากการเดินครบ 5 ขั้นบน production build ขนาดจอมือถือ (รอบทดสอบที่ 5 และการแก้รอบ 6 วันที่ 17 ต.ค. 2569) เรื่องที่ Winyu สืบให้ต้องเรียกโมเดลตอนเช้า หัวเรื่องและตัวเลขจึงต่างไปได้ในแต่ละวัน ส่วนปุ่ม ชื่อหัวข้อ และลำดับขั้นเหมือนเดิม

## เช้าวันงาน (ประมาณ 10 นาที)

1. หยุด server ก่อน สำรองไฟล์ connector แล้วคืนข้อมูลให้สะอาด

   ```bash
   mkdir -p /tmp/winyu-keep && cp .data/{connectors,connector-secrets,connector-health,connector-upstream,secrets,mcp-tokens,identity-links}.json /tmp/winyu-keep/
   bun run seed
   cp /tmp/winyu-keep/*.json .data/
   ```

   `bun run seed` ลบทุกไฟล์ JSON ใน `.data` รวมถึงแชตเก่า เรื่องที่ส่งกันในการซ้อม และ connector ที่เพิ่มจากหน้า admin จึงต้องสำรองแล้วคืนไฟล์ connector ตามคำสั่งข้างบน seed ไม่ได้ส่งเรื่องให้ใครไว้ก่อน เรื่องแรกบนเวทีจึงเป็นเรื่องที่ CEO ส่งเอง

2. สั่ง Winyu สืบให้ 4 คน (ประมาณ 22 model calls รวม $0.23 ใช้เวลา 2 ถึง 4 นาที)

   ```bash
   bun run investigate -- --users=u_thana,u_anucha,u_krit,u_ton --save
   ```

   ผลที่ควรเห็น: CEO มี 3 ถึง 4 เรื่องด่วน (ทุกความผิดปกติระดับ P1 ได้เรื่องของตัวเอง จำนวนขึ้นกับข้อมูลเช้านั้น) และเรื่องบนสุดคือ "ภาคอีสาน · …ยอดขายเข้าภาคอีสานจะปิดเดือนต่ำกว่าเป้า"

3. build แล้วเปิด connector ตัวอย่างกับ server แบบ production (เร็วกว่า dev และไม่มีปุ่ม "N" ของ Next)

   ```bash
   bun run build
   bun run connectors:demo &
   WINYU_SCHEDULER=off WINYU_AUTH=demo bun run start
   ```

   ต้องใส่ `WINYU_AUTH=demo` เสมอ ถ้าไม่ใส่ production build จะใช้การเข้าระบบแบบ Entra และไม่มีการ์ดเลือกบทบาท ถ้าเครื่องไม่พอ build ใช้ `make up` (โหมด dev) แทนได้ แต่ตอบช้ากว่าและมีปุ่ม "N" มุมซ้ายล่าง

   หน้าแรกของ CEO ต้องขึ้นป้าย "Winyu สืบให้แล้ว · N เรื่องด่วน" (3 หรือ 4) ถ้าขึ้นว่า "Winyu ยังไม่ได้สืบให้วันนี้" แปลว่าข้อ 2 ยังไม่เสร็จหรือไม่สำเร็จ

`bun run call-tool` ใช้ส่งงานล่วงหน้าแทนการกดบนจอไม่ได้ เครื่องมือที่เขียนข้อมูลต้องมีการกดอนุมัติจากคนนั้นบันทึกไว้ก่อน ถ้าลองสั่ง ระบบจะตอบ `NOT_APPROVED` และไม่ส่งอะไรออกไป

## จัดจอ

เปิด 4 หน้าต่างใน Chrome ตัวเดียว แต่ละหน้าต่างใช้ที่อยู่ของตัวเอง แล้วลากให้แคบเท่าจอมือถือ

| หน้าต่าง | ที่อยู่ | กดการ์ด "เริ่มเดโมที่นี่" ใบที่ | เข้าเป็น |
|---|---|---|---|
| 1 | `http://ceo.localhost:3100` | ขั้นที่ 1 | คุณธนา ประธานเจ้าหน้าที่บริหาร |
| 2 | `http://rsm.localhost:3100` | ขั้นที่ 2 | คุณอนุชา ผู้จัดการขายภาค ภาคอีสาน |
| 3 | `http://rep.localhost:3100` | ขั้นที่ 3 | คุณกฤต พนักงานขาย ขอนแก่น |
| 4 | `http://it.localhost:3100` | ขั้นที่ 4 | คุณต้น ผู้ดูแลระบบไอที (เข้าแล้วไปที่ Admin console ทันที) |

แต่ละที่อยู่เก็บการเข้าระบบของตัวเองใน cookie แยกกัน ถ้าทุกหน้าต่างใช้ `localhost:3100` เหมือนกัน คนที่เข้าล่าสุดจะทับทุกหน้าต่าง เข้าครบแล้วกด reload ทุกหน้าต่างหนึ่งครั้งเพื่อเช็กว่ายังเป็นคนเดิม

ถ้าใช้โหมด dev ปุ่ม "N" มุมซ้ายล่างคือเครื่องมือของ Next มันบังปุ่มและข้อความที่มุมซ้ายล่างได้ กดแล้วเลือกซ่อนก่อนขึ้นเวที

## ลำดับบนเวที

### 1. CEO ส่งเรื่อง (หน้าต่าง 1)

1. กดป้าย **Winyu สืบให้แล้ว · N เรื่องด่วน** ใต้คำทักทาย แผง "N เรื่องด่วน" เปิดขึ้น เรื่องยอดขายเข้าภาคอีสาน (ป้าย "ด่วน") อยู่บนสุดและกางอยู่แล้ว ไม่ต้องกดซ้ำ ถ้ากดหัวเรื่องจะพับเก็บ บางวันในแผงมีอีกเรื่องที่ขึ้นว่าภาคอีสานด้วย (ส่วนแบ่งตลาดนครราชสีมา) ให้ใช้เรื่องบนสุดเสมอ
2. ใต้หัวเรื่องคือการ์ดหลักฐานเป็นบาท: ตัวเลขใหญ่คือ % ของเป้าทั้งเดือน เส้นแบ่งคือ "ถึงวันนี้ควรได้ …%" และแถวละเอเย่นต์ แถวที่อยู่ต่ำกว่าเส้นเป็นสีแดง
3. กด **ส่งต่อ** ที่มุมขวาล่างของการ์ด ชีต "ส่งต่อการ์ดนี้" เปิดขึ้น หัวชีตเป็นชื่อการ์ด (เช่น "มูลค่าขายเข้า · รายเอเย่นต์" ตามที่การ์ดของวันนั้นแสดง)
4. เช็กในชีต: เลือก **ต้องตอบ** อยู่แล้ว, "ต้องการเมื่อไร" เป็น **วันนี้** (กด **ด่วน** ถ้าอยากเน้น), ช่อง "ขออะไร" เป็นหัวเรื่องที่ Winyu สืบได้, สวิตช์ "ปิดเองเมื่อ … ถึง 100% ของเป้า" เปิดอยู่แล้ว, กลุ่ม "ผู้รับผิดชอบเรื่องนี้" มีแค่ คุณอนุชา พรหมศรี และเลือกไว้แล้ว คนในสายของ CEO อยู่อีกกลุ่มชื่อ "ทีมของคุณ"
5. กด **ส่ง** ที่มุมขวาล่าง ปุ่มใต้การ์ดเปลี่ยนเป็น **ส่งแล้ว** สีเขียว และใต้การ์ดมีบรรทัด "ส่งต่อแล้วเมื่อ <วัน เวลา>" บอกผู้รับพร้อมลิงก์ ถึงจะเปลี่ยนหน้าหรือ reload ก็ยังขึ้น "ส่งแล้ว" (✕ ซ่อนบรรทัดนั้นจนกว่าจะโหลดหน้าใหม่) จึงไม่ส่งการ์ดใบเดิมซ้ำโดยไม่ตั้งใจ

พูด: "Winyu สืบให้ตั้งแต่เช้า ผมแค่ตรวจแล้วกดส่ง ไม่ต้องพิมพ์ ไม่ต้องรอ AI"

ถ้ามีคนถามว่าทำไมไม่ส่งตามที่เรื่องแนะนำ (เรื่องอาจแนะนำให้ถามผู้อำนวยการฝ่ายขายหรือฝ่ายการเงิน): ชีตเลือกผู้รับผิดชอบเรื่องโดยตรงไว้ให้ CEO เปลี่ยนผู้รับเองได้

### 2. ผู้จัดการขายภาคส่งต่อ (หน้าต่าง 2)

1. ไม่ต้องคลิกอะไร กระดิ่งขึ้นเลข 1 เองภายในประมาณ 10 วินาทีขณะที่หน้าต่างเปิดอยู่
2. กดกระดิ่ง แผง "แจ้งเตือน" เปิดจากด้านล่าง ใต้หัวข้อ "ต้องตัดสินใจ" มีเรื่องเดียว: บรรทัดแรกเป็นชื่อการ์ด ต่อด้วยสิ่งที่ CEO ขอ และ "จากคุณธนา วงศ์สกุล" ใต้รายการมีปุ่ม **รับ**, **ขอข้อมูลเพิ่ม**, **ส่งต่อ**
3. กดชื่อการ์ดในรายการนั้น หน้าเรื่องเปิดขึ้น: การ์ดเดียวกันตามสิทธิ์ของผู้จัดการภาค ตัวเลขเดียวกับที่ CEO เห็น บนจอมือถือปุ่ม **รับ** **ขอข้อมูลเพิ่ม** **ส่งต่อ** และ "เส้นทางของเรื่อง" อยู่ใต้การ์ด ต้องเลื่อนลง ระวังอย่ากดปุ่มดำในการ์ด (เช่น **ตรวจสาเหตุ**) เพราะปุ่มนั้นถามโมเดลและเปิดแชตใหม่
4. กด **ส่งต่อ** กล่อง "เลือกคนที่จะรับเรื่องต่อ" เปิดขึ้นและเลื่อนมาให้เห็นเอง คุณกฤต จันทร์เสน อยู่บนสุดในกลุ่ม "ทีมของคุณ" เลือกคุณกฤต แล้วกด **ส่งต่อ** ใต้กล่อง ปุ่มขึ้น "กำลังส่งต่อ…" ครู่หนึ่ง และเลขบนกระดิ่งของผู้จัดการภาคหายทันที

ทางลัด: กด **ส่งต่อ** ในแผงกระดิ่งได้เลยโดยไม่ต้องเปิดหน้าเรื่อง แต่ผู้ชมจะไม่เห็นการ์ดตามสิทธิ์ของผู้จัดการภาค

พูด: "การ์ดเดียวกัน เปิดใหม่ด้วยข้อมูลสดตามสิทธิ์ของผู้รับ ตัวเลขไม่ได้แนบไปกับข้อความ และไม่ต้องเล่าเรื่องใหม่ให้ลูกทีมฟัง"

### 3. พนักงานขายรับเรื่อง (หน้าต่าง 3)

1. กระดิ่งขึ้นเลข 1 เอง กดกระดิ่ง รายการใต้ "ต้องตัดสินใจ" บอก "จากคุณธนา วงศ์สกุล · ส่งต่อโดยคุณอนุชา พรหมศรี" (ถ้าเปิดแผงกระดิ่งค้างไว้ก่อน รายการจะขึ้นในแผงเองภายในราว 10 วินาที)
2. กด **รับ** ในรายการนั้น บรรทัด "รับเรื่องแล้ว … · เปิดเรื่อง" ขึ้นบนสุดของแผง (หรือกดชื่อการ์ดเพื่อเปิดหน้าเรื่องก่อน แล้วกด **รับ** ในหน้าเรื่อง)

พูด: "ทุกคนในสายเห็นสถานะเดียวกัน ไม่ต้องโทรตาม"

### 4. CEO เห็นเส้นทาง (หน้าต่าง 1)

1. ถ้าแผงเรื่องด่วนยังเปิดอยู่ กด ✕ (ปุ่ม "ปิดเรื่องที่ Winyu สืบ") ปิดก่อน กระดิ่งของ CEO มีจุดแดง (อัปเดต ไม่ใช่งานที่ต้องตัดสินใจ จึงไม่มีตัวเลข) จุดหายเมื่อปิดแผงกระดิ่ง
2. กดกระดิ่ง ใต้หัวข้อ "อัปเดต" มี 2 รายการ: "คุณกฤต จันทร์เสน รับเรื่อง "…"" และ "คุณอนุชา พรหมศรี ส่งต่อเรื่อง "…" ให้ คุณกฤต จันทร์เสน"
3. กดรายการใดก็ได้ หน้าเรื่องขึ้นหัวว่า "เรื่องที่คุณส่งไป รอคำตอบ" เลื่อนลงใต้การ์ดจะเห็น "เส้นทางของเรื่อง": คุณธนา ผู้ส่ง → คุณอนุชา ส่งต่อแล้ว → คุณกฤต รับแล้ว (ปุ่ม **ปิดเรื่อง** ของผู้ส่งเป็นปุ่มรอง และถามก่อนปิด)

พูด: "CEO รู้ว่างานไปถึงใครแล้ว โดยไม่ต้องถามสักคน"

### 5. ฝ่ายไอทีเห็นทุกขั้น (หน้าต่าง 4)

1. ใน Admin console กดแท็บ **Audit** (บนจอมือถือแท็บเรียงเป็น 5 ช่อง ไอคอนอยู่เหนือชื่อ)
2. กดชิป **การส่งงานและการแก้ไข** (ถ้าอยากเปิดตรง ใช้ `http://it.localhost:3100/admin?tab=audit&kind=activity`)
3. แผง "ใครส่งงานอะไรให้ใคร" แสดงใหม่สุดก่อน 3 แถว: คุณกฤต รับเรื่อง, คุณอนุชา ส่งต่อ → คุณกฤต จันทร์เสน, คุณธนา ส่งเรื่อง → คุณอนุชา พรหมศรี แต่ละแถวมีชื่อคนบรรทัดแรก บทบาทกับเวลาบรรทัดที่สอง สิ่งที่ทำ ชื่อการ์ด และป้าย "กดเองบนการ์ด" แผงนี้อัปเดตเองภายในราว 10 วินาที ไม่ต้อง reload

พูด: "ไอทีเห็นว่าใครส่งอะไรให้ใคร เมื่อไร และใครอนุมัติ แต่ไม่เห็นข้อความที่แต่ละคนพิมพ์"

ถ้ามีเวลา ให้ถาม Winyu ในแชตของไอทีว่า "สัปดาห์นี้ใครส่งงานอะไรให้ใครบ้าง" Winyu ตอบเป็นการ์ดรายการที่อ่านได้บนจอมือถือ (เรียกโมเดล ใช้เวลาหลายวินาที)

## ทางเลือก: CEO สั่งในแชต

ใช้เมื่ออยากโชว์ว่าพิมพ์สั่งได้ ช้ากว่าการกด **ส่งต่อ** มากเพราะต้องรอโมเดลสองรอบ

1. ในเรื่องภาคอีสาน กด **ถามต่อ** ใต้คำแนะนำของเรื่อง แชตใหม่เปิดขึ้นและ Winyu เริ่มตอบเรื่องนั้นเองทันที (รอบ 4 ใช้ราว 25 วินาที) รอให้ตอบเสร็จก่อน
2. พิมพ์ **ส่งเรื่องนี้ให้ผู้จัดการขายภาคอีสาน ด่วน** แล้วกดปุ่มลูกศร ↑ ข้างช่องพิมพ์ (ชื่อปุ่ม "ส่งข้อความ") (บนจอมือถือ Enter คือขึ้นบรรทัดใหม่)
3. Winyu ตอบด้วยการ์ดอนุมัติ "ส่งการ์ดให้ คุณอนุชา พรหมศรี" ที่แสดงชื่อการ์ด ตัวเลขเดียวกับการ์ด สิ่งที่ขอ และความด่วน
4. กด **ส่ง** (หรือ **ยังไม่ส่ง** ถ้าจะยกเลิก) จากนั้นทำขั้น 2 ถึง 5 ตามเดิม ในหน้า Audit แถวของ CEO จะเป็น "คุณธนา วงศ์สกุล ยืนยันในแชต" แทน "กดเองบนการ์ด" การ์ดใบแรกในแชตขึ้น "ส่งแล้ว" อยู่แล้วเพราะเป็นการ์ดใบเดียวกับที่ส่งในขั้น 1 ส่วนเรื่องที่สองนี้ใช้ชื่อการ์ดเดิม ในกระดิ่งของ CEO บรรทัดอัปเดตจะบอกสิ่งที่ขอต่อท้ายเพื่อแยกสองเรื่อง "(ครั้งที่ 2)" ขึ้นเฉพาะเมื่อส่งเรื่องเดิมให้คนเดิมด้วยคำขอเดิมซ้ำ

ถ้าพิมพ์ข้อความใหม่ขณะที่การ์ดอนุมัติยังรออยู่ ระบบนับว่ายกเลิก การ์ดนั้นขึ้นว่า "ไม่ได้ส่งการ์ด · ยกเลิกไว้ เพราะคุณถามเรื่องใหม่" และ Winyu ตอบคำถามใหม่ตามปกติ

## ถ้าเกิดเหตุ

| อาการ | ทำอะไร |
|---|---|
| หน้าแรก CEO ขึ้น "Winyu ยังไม่ได้สืบให้วันนี้" | รัน `bun run investigate` ตามข้อ 2 ของช่วงเช้าแล้ว reload ถ้าไม่ทัน ให้ใช้ทางเลือกในแชต |
| เผลอกดปุ่มดำในการ์ด (ตรวจสาเหตุ, ส่งให้…) แล้วแชตใหม่เปิดขึ้น | กดย้อนกลับของเบราว์เซอร์ หรือกระดิ่งแล้วกดชื่อการ์ดอีกครั้ง ขั้นที่ทำไปแล้วไม่หาย |
| กระดิ่งไม่ขยับเกิน 10 วินาที | กระดิ่งดึงข้อมูลใหม่เฉพาะตอนหน้าต่างมองเห็นอยู่ คลิกที่หน้าต่างนั้นหนึ่งครั้ง หรือกด reload |
| การ์ดอนุมัติขึ้นว่า "ยกเลิกไว้ เพราะคุณถามเรื่องใหม่" | มีคนพิมพ์ข้อความใหม่ตอนที่การ์ดยังรออยู่ ให้สั่งส่งใหม่แล้วกด **ส่ง** ก่อนพิมพ์อย่างอื่น |
| reload ระหว่างที่ Winyu กำลังตอบ | ไม่ต้องทำอะไร หน้าแชตต่อเข้ากับคำตอบที่ยังทำอยู่เอง |
| หน้าต่างกลายเป็นคนอื่น | ดูที่อยู่ ทุกหน้าต่างต้องใช้ที่อยู่ของตัวเองตามตาราง ถ้าเปิด `localhost:3100` เปล่า ๆ การเข้าระบบจะทับกัน |
| ชีตส่งต่อไม่ได้ติ๊กคุณอนุชาไว้ | พิมพ์ "อนุชา" ในช่องค้นหาแล้วติ๊กเอง |
| พนักงานขายเห็นเรื่องในกระดิ่งมากกว่า 1 เรื่อง | มาจากการซ้อมรอบก่อน ให้ทำช่วงเช้าข้อ 1 ถึง 3 ใหม่ก่อนขึ้นเวที |
| แผง Audit ว่าง | ดูว่าช่วงเวลาเป็น "7 days" และไม่ได้เลือกผู้ใช้ไว้ แล้วกด "Clear" |

## ค่าใช้จ่ายต่อรอบ

การสืบตอนเช้าราว 22 model calls รวม $0.23 สำหรับ 4 คน (วัดเมื่อ 17 ต.ค.) ขั้น 1 ถึง 5 แบบกดบนการ์ดไม่เรียกโมเดลเลย ทางเลือกในแชตเรียกโมเดลทั้งตอน **ถามต่อ** และตอนสั่งส่ง ซ้อมกี่รอบก็ได้ แต่ต้องทำช่วงเช้าข้อ 1 ถึง 3 ใหม่ก่อนขึ้นเวทีจริง
