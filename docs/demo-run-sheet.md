# Run sheet: เดโม Winyu แบบหลายจอ

เรื่องเดียว 4 คน: ยอดภาคอีสานหลุดเป้า ส่งต่อจาก CEO ลงไปถึงพนักงานขาย แล้วฝ่ายไอทีเห็นทุกอย่างใน Audit ทุกขั้นในเอกสารนี้ลองเล่นจริงบนเครื่องแล้วเมื่อ 16 ต.ค. 2569 ตัวเลขและเวลาที่เขียนไว้มาจากรอบนั้น คำตอบจริงของโมเดลอาจใช้ถ้อยคำต่างไปบ้าง

## เช้าวันงาน (ประมาณ 10 นาที)

1. คืนข้อมูลให้สะอาด เพื่อไม่ให้งานจากการซ้อมค้างอยู่ในกระดิ่ง หยุด server ก่อน แล้วรัน

   ```bash
   bun run seed
   ```

   คำสั่งนี้ลบทุกไฟล์ JSON ใน `.data` รวมถึงแชตเก่าและ connector ที่เพิ่มจากหน้า admin ถ้ายังต้องใช้ connector พวกนั้น ให้สำรองไฟล์ `.data/connectors.json` และ `.data/secrets.json` ไว้ก่อน

2. สั่ง Winyu สืบให้ 4 คนในเรื่องนี้ (ประมาณ 28 calls ไม่ถึง $0.2 ใช้เวลาราว 2 ถึง 4 นาที)

   ```bash
   bun run investigate -- --users=u_thana,u_anucha,u_krit,u_ton --save
   ```

3. เปิด server โดยปิดงานเบื้องหลัง

   ```bash
   WINYU_SCHEDULER=off bun run dev
   ```

   หน้าแรกของ CEO ต้องขึ้นว่า "Winyu สืบให้แล้ว · 3 เรื่องด่วน" ถ้าขึ้นว่า "ยังไม่ได้สืบให้วันนี้" แปลว่าข้อ 2 ยังไม่เสร็จหรือไม่สำเร็จ

## จัดจอ

เปิด 4 หน้าต่างใน Chrome ตัวเดียว แต่ละหน้าต่างใช้ที่อยู่ของตัวเอง

| หน้าต่าง | ที่อยู่ | เข้าเป็น |
|---|---|---|
| 1 | `http://ceo.localhost:3100` | ประธานเจ้าหน้าที่บริหาร |
| 2 | `http://rsm.localhost:3100` | ผู้จัดการขายภาค ภาคอีสาน |
| 3 | `http://rep.localhost:3100` | พนักงานขาย ขอนแก่น |
| 4 | `http://it.localhost:3100` | ผู้ดูแลระบบไอที |

ทำไมต้องคนละที่อยู่: การเข้าระบบเก็บไว้ใน cookie หนึ่งตัวต่อที่อยู่ ถ้าทั้ง 4 หน้าต่างใช้ `localhost:3100` เหมือนกัน คนที่เข้าล่าสุดจะทับคนก่อนหน้าทุกหน้าต่าง Chrome ส่ง `*.localhost` มาที่เครื่องนี้เองโดยไม่ต้องตั้งค่าอะไร

ในแต่ละหน้าต่าง หน้า login จะมี "เริ่มเดโมที่นี่" 4 การ์ดเรียงตามลำดับ ให้กดการ์ดที่ตรงกับหน้าต่างนั้น แล้วลากหน้าต่างให้แคบที่สุด จะได้หน้าจอแบบมือถือ เข้าครบแล้วกด reload ทุกหน้าต่างหนึ่งครั้ง เพื่อเช็กว่าแต่ละหน้าต่างยังเป็นคนเดิม

ปุ่ม "N" มุมซ้ายล่างเป็นเครื่องมือของ Next ในโหมด dev ถ้าไม่อยากให้ติดบนจอ ให้กดที่ปุ่มแล้วเลือกซ่อน

## ลำดับบนเวที

### 1. CEO: "Winyu สืบให้แล้ว" (หน้าต่าง 1)

- กดป้าย "Winyu สืบให้แล้ว · 3 เรื่องด่วน" ใต้คำทักทาย
- กดเรื่องภาคอีสาน "ยอดขายเข้าจะปิดต่ำกว่าเป้าจากอีสานรุ่งโรจน์และอุบลศรีสุขที่ติดล็อควงเงินเครดิต" จะเห็นเอเย่นต์ 2 รายตกราว 30% เทียบเป้า
- กด "ถามต่อ" Winyu ดึงยอดขายเข้า ยอดค้างชำระ และความผิดปกติมาให้เอง (ประมาณ 30 วินาที)
- พิมพ์: **ส่งเรื่องนี้ให้ผู้จัดการขายภาคอีสานไปจัดการ ด่วน** แล้วกดปุ่มส่ง (บนจอมือถือ Enter คือขึ้นบรรทัดใหม่ ไม่ส่ง)
- การ์ด "ส่งงานให้ คุณอนุชา" ขึ้นมาพร้อมเรื่อง สิ่งที่ขอ และหลักฐานที่แนบ (ประมาณ 25 ถึง 40 วินาที) กด **อนุมัติและส่งงาน**

ประเด็นที่พูด: Winyu สืบให้ตั้งแต่เช้า ไม่ต้องถาม ตัวเลขทุกตัวมาจากระบบ และไม่มีอะไรถูกส่งออกไปจนกว่าคนจะกดอนุมัติ

### 2. ผู้จัดการขายภาคอีสาน (หน้าต่าง 2)

- คลิกเข้าหน้าต่าง 2 กระดิ่งจะขึ้น "1 เรื่องรอคุณตัดสินใจ" เองทันทีที่สลับมา
- กดกระดิ่ง แล้วกด "งานใหม่จาก คุณธนา…" Winyu เปิดงานแล้วดึงหลักฐานใหม่ด้วยสิทธิ์ของผู้จัดการภาคเอง และบอกว่าควรตรวจอะไรก่อน (ประมาณ 30 วินาที)
- พิมพ์: **ส่งงานให้คุณกฤตไปตามออเดอร์อุบลศรีสุขเลย** แล้วกด **อนุมัติและส่งงาน** (ประมาณ 15 วินาที)

ประเด็นที่พูด: คำถามเดียวกัน แต่ผู้จัดการภาคเห็นเฉพาะภาคอีสาน งานที่ส่งมาพกหลักฐานมาด้วย ไม่ต้องเล่าใหม่

### 3. พนักงานขาย ขอนแก่น (หน้าต่าง 3)

- คลิกเข้าหน้าต่าง 3 กระดิ่งขึ้น "งานใหม่จาก คุณอนุชา: ติดตามคำสั่งซื้อขายเข้า อุบลศรีสุข เทรดดิ้ง"
- กด **รับงาน**
- กลับไปหน้าต่าง 2 กระดิ่งของผู้จัดการภาคขึ้น "คุณกฤต จันทร์เสน: รับงานแล้ว กำลังตรวจสอบข้อมูลครับ"

ประเด็นที่พูด: ทุกคนในสายเห็นสถานะเดียวกัน ไม่ต้องโทรตาม

อย่าถามคำถามยาวในขั้นนี้ ตอนซ้อม คำถาม "ต้องไปเอเย่นต์ไหนก่อน" ใช้เวลา 62 วินาที

### 4. ฝ่ายไอที (หน้าต่าง 4)

- Admin console หน้าภาพรวม การ์ด "ถูกปฏิเสธล่าสุด" แสดงคำถามที่ถูกกันเพราะเกินสิทธิ์ ตอนซ้อมมีรายการของผู้จัดการภาคที่ขอดูข้อมูลนอกภาคตัวเอง
- กดแท็บ Audit เพื่อดูทุกการเรียกเครื่องมือของ 3 คนก่อนหน้า ว่าใครทำ ทำอะไร และระบบอนุญาตหรือปฏิเสธ

ประเด็นที่พูด: สิทธิ์บังคับในโค้ด ไม่ได้ฝากไว้กับ prompt และทุกอย่างมีบันทึกให้ตรวจย้อนหลังได้

## ถ้าเกิดเหตุ

| อาการ | ทำอะไร |
|---|---|
| คำตอบช้ากว่า 40 วินาที | พูดประเด็นของขั้นนั้นไปก่อน คำตอบยาวบางครั้งใช้เกิน 60 วินาที |
| กระดิ่งไม่เปลี่ยน | คลิกที่หน้าต่างนั้นหนึ่งครั้ง หรือกด reload |
| หน้าต่างกลายเป็นคนอื่น | ดูที่อยู่ ทุกหน้าต่างต้องใช้ที่อยู่ของตัวเองตามตารางข้างบน |
| Winyu ตอบด้วยถ้อยคำต่างจากที่เขียนไว้ | ไม่เป็นไร ตัวเลขมาจากเครื่องมือเสมอ ถ้าไม่มีการ์ด "ส่งงานให้" ขึ้นมา ให้พิมพ์ชื่อคนตรง ๆ เช่น "ส่งให้คุณอนุชา" |

## ค่าใช้จ่ายต่อรอบ

การสืบตอนเช้าไม่ถึง $0.2 สำหรับ 4 คน การเล่นครบ 4 ขั้นใช้ประมาณ 6 ถึง 8 calls ราว $0.05 ซ้อมได้หลายรอบ แต่ควร `bun run seed` และสั่งสืบใหม่ก่อนขึ้นเวทีจริง

## ลิงก์ demo สาธารณะ (GKE)

ลิงก์สาธารณะมีที่อยู่เดียว จึงใช้วิธี `*.localhost` ไม่ได้ ถ้าต้องเล่นหลายจอบนลิงก์นั้น ให้เปิดแต่ละคนใน Chrome profile แยกกัน หรือใช้มือถือจริงคนละเครื่อง
