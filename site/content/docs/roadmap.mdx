## สี่ขั้น

<Steps>
<Step>

### ตัวตนและสิทธิ์

ต่อ SSO และตารางว่าใครดูแลภาคหรือแบรนด์ไหน ทุกกลไกสิทธิ์ของ Winyu เริ่มจากตรงนี้

องค์กรเตรียม: กลุ่มใน Entra ID และแหล่งข้อมูลขอบเขตความรับผิดชอบ

</Step>
<Step>

### ตัวเลขจากคลังข้อมูล

ต่อประตูตัวเลขแบบอ่านอย่างเดียว เปิดแดชบอร์ดและคำถามเรื่อง KPI ด้วยข้อมูลจริง

องค์กรเตรียม: บัญชีอ่าน และนิยาม metric

</Step>
<Step>

### ข้อมูลรายเรื่อง

ต่อ HR, LMS, SFA ผ่าน API gateway ด้วย REST หรือ MCP connector ทีละระบบ

องค์กรเตรียม: endpoint บน gateway หรือ MCP server

</Step>
<Step>

### เขียนกลับระบบเดิม

ส่งคำขอลา ลงทะเบียนอบรม หรือคำสั่งงาน เข้า workflow อนุมัติที่มีอยู่ ระหว่างนี้คำขอเหล่านี้อยู่ใน Inbox ของ Winyu

องค์กรเตรียม: workflow และสิทธิ์เขียน

</Step>
</Steps>

## งานฝั่ง Winyu ที่ยังต้องทำ

| งาน | สถานะ |
|---|---|
| port ของทุกระบบต้นทาง และขั้นตอนสิทธิ์กลาง | ทำแล้ว |
| MCP connector พร้อม red-team test | ทำแล้ว |
| หน้า admin: สิทธิ์ต่อ tool, kill switch, audit ตาม connector | ทำแล้ว |
| แยกส่วนดึงข้อมูลออกจากขั้นตอนสิทธิ์ของประตูตัวเลข | ยังไม่ทำ ทำได้โดยไม่ต้องรอองค์กร |
| REST connector | ยังไม่ทำ ทำได้โดยไม่ต้องรอองค์กร |
| SSO จริงและ token แบบ on-behalf-of | ยังไม่ทำ รอข้อมูลตัวตนขององค์กร |
| adapter ของคลังข้อมูลตัวจริง | ยังไม่ทำ รอรู้ว่าองค์กรใช้ตัวไหน |
| cache และ timeout ของ query ตัวเลข | ยังไม่ทำ ก่อนเปิดให้ผู้ใช้จำนวนมาก |
| ย้ายการแจ้งเตือนและพยากรณ์ไปอ่านข้อมูลจริง | ยังไม่ทำ |
| เขียนกลับระบบต้นทาง | ยังไม่ทำ |
