## สิ่งที่ต้องมี และสิ่งที่ไม่ต้องทำ

| ระบบ | ต้องมี | ไม่ต้องทำ |
|---|---|---|
| คลังข้อมูล / BI | บัญชีอ่านอย่างเดียว · นิยาม metric (view, semantic view หรือ dbt) · รหัสภาค แบรนด์ เอเย่นต์ที่คงที่ · เวลาอัปเดตข้อมูล | ไม่เปลี่ยน schema ไม่ย้ายข้อมูล ไม่ sync มาให้ Cop |
| HR · LMS · SFA · ระบบลา | API ให้อ่าน (REST หรือ MCP) · ถ้าจะบังคับสิทธิ์เอง ให้รับตัวตนผู้ใช้จาก Cop | ไม่เพิ่มหน้าจอ ไม่ทำ export |
| ตัวตนผู้ใช้ (SSO) | login ผ่าน Entra ID / AD · กลุ่มที่บอกบทบาท · ข้อมูลว่าใครดูแลภาคหรือแบรนด์ไหน | ไม่สร้างบัญชีผู้ใช้ชุดใหม่ |
| เครือข่าย | เซิร์ฟเวอร์ Cop เข้าถึงระบบต้นทางได้ (private network / VPN) | ไม่เปิดระบบต้นทางออกอินเทอร์เน็ต |

<Callout title="สิ่งเดียวที่อาจยังไม่มี">
ข้อมูลว่าใครดูแลภาคหรือแบรนด์ไหน บางองค์กรเก็บไว้ในระบบ HR บางที่อยู่ใน AD และบางที่อยู่ในไฟล์ของฝ่ายขาย Cop ตัดสินสิทธิ์จากข้อมูลนี้ จึงต้องหาแหล่งที่เชื่อถือได้ก่อนเปิดใช้ข้อมูลจริง
</Callout>

## ภาพระบบที่พบบ่อยในองค์กรขนาดใหญ่

สมมติฐานสำหรับเริ่มคุย ต้องยืนยันกับทีมขององค์กรทุกข้อ

| กลุ่มระบบ | ที่พบบ่อย | Cop ต่อผ่าน |
|---|---|---|
| ERP | SAP ECC / S/4HANA | อ่านผ่านคลังข้อมูล ไม่อ่านตรง |
| คลังข้อมูล · BI | SAP BW, SQL Server, Snowflake · Power BI | ประตูตัวเลข |
| ขายภาคสนาม · DMS | SFA ที่พัฒนาเอง, Salesforce | REST ผ่าน gateway |
| HR · LMS · ลา | SuccessFactors, HRM ไทย, LMS ของ vendor | REST หรือ MCP |
| ตัวตน · อีเมล | Active Directory, Entra ID, M365 | SSO, Microsoft Graph |
| ระบบเก่าไม่มี API | ฐานข้อมูล, ไฟล์ส่งทุกคืน | อ่านจากสำเนาในคลังข้อมูล |

ทำไมตัวเลขต้องอ่านผ่านคลังข้อมูล: ตัวเลขที่ผู้บริหารใช้ในที่ประชุมผ่านการกระทบยอดในคลังข้อมูลมาแล้ว ถ้า Cop อ่านจาก ERP เอง ตัวเลขจะไม่ตรงกับรายงานเดิม และความเชื่อถือจะหายไปทันที

## คำถามวันแรก

1. ตัวเลขในที่ประชุมผู้บริหารมาจากคลังข้อมูลหรือ BI ตัวไหน และมี semantic model ที่รับรองแล้วไหม
2. มี API gateway หรือ middleware กลางไหม ทีมไหนดูแล
3. ระบบ HR, LMS, SFA และระบบลาใช้ของอะไร มี API หรือ MCP ไหม
4. login ใช้ Entra ID หรือ AD ไหม ข้อมูลว่าใครดูแลภาคไหนอยู่ที่ระบบไหน
5. นโยบายยอมให้ใช้บัญชี service อ่านคลังข้อมูล หรือต้องส่งตัวตนผู้ใช้ทุกคำขอ
6. ข้อมูลในคลังข้อมูลอัปเดตถี่แค่ไหน รายวันหรือใกล้เคียงเวลาจริง
