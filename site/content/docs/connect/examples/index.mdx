## ขั้นตอนที่เหมือนกันทุกตัวอย่าง

1. เขียน config ใน `lib/server/connectors/<ชื่อ>.ts`
2. เพิ่ม connector ลงในรายการ `CONFIGURED` ของ `lib/server/connectors/index.ts`
3. เก็บ URL และ secret ใน environment variable ของ server เท่านั้น
4. เขียนเทสต์ตาม[ตัวอย่างการทดสอบ](/docs/connect/examples/testing)
5. เปิดหน้า admin แท็บสิทธิ์ตามบทบาท ตรวจว่า tool และฟิลด์อ่อนไหวขึ้นตามที่ตั้งไว้
