Cop มี port สำหรับระบบที่พบบ่อยในองค์กร tool ในบ้าน เช่น `request_leave`, `find_people`, `get_calendar` อ่านผ่าน port เหล่านี้ และมีกติกาของบริษัทอยู่ในตัวแล้ว เช่น ต้องลาพักร้อนล่วงหน้ากี่วันทำการ

| port | ระบบต้นทาง | ใช้โดย |
|---|---|---|
| `metrics` | คลังข้อมูล | แดชบอร์ด แชท การแจ้งเตือน |
| `directory` | ระบบ HR (รายชื่อ ตำแหน่ง สายบังคับบัญชา) | `find_people`, `get_person` และการตรวจสิทธิ์เรื่องคน |
| `recruiting` | ระบบสรรหา | `list_candidates` |
| `learning` | ระบบอบรม | `list_courses`, `enroll_course` |
| `leave` | ระบบลา | `request_leave`, `get_policy` |
| `sites` | ระบบสาขาและเหตุการณ์ | `get_site` |
| `calendar` | วันหยุด วันห้ามขาย เทศกาล | `get_calendar`, การนับวันทำการของ `request_leave` |
| `mail` | อีเมลหรือ LINE | `send_email`, การส่งงาน การแจ้งเตือน และสรุปตอนเช้า |

## ตัวอย่าง: วันลาจากระบบ HR

```ts
export type LeavePort = {
  policy(): Promise<LeavePolicy>;
  usedThisYear(employeeId: string): Promise<Readonly<Record<LeaveKind, number>>>;
};
```

```ts
const LEAVE_KINDS_FROM_HR: Record<string, LeaveKind> = { AL: "annual", SL: "sick", PL: "personal" };

export const hrLeavePort: LeavePort = {
  policy: GENERATOR_PORTS.leave.policy,
  usedThisYear: async (employeeId) => {
    const response = await fetch(`${env.HR_API_URL}/employees/${encodeURIComponent(employeeId)}/leave-used`);
    const items = z.array(z.object({ code: z.string(), days: z.number() })).parse(await response.json());
    const used: Record<LeaveKind, number> = { annual: 0, sick: 0, personal: 0 };
    for (const item of items) {
      const kind = LEAVE_KINDS_FROM_HR[item.code];
      if (kind) used[kind] += item.days;
    }
    return used;
  },
};
```

แล้วแก้ค่าเริ่มต้นใน `lib/server/ports/index.ts`

```ts
let current: Ports = { ...GENERATOR_PORTS, leave: hrLeavePort };
```

## port กับ connector ต่างกันอย่างไร

| | port | connector |
|---|---|---|
| ใครตัดสินว่าจะเรียกเมื่อไร | tool ในบ้านของ Cop ซึ่งมีกติกาและการ์ดของตัวเอง | AI เลือกจาก `description` |
| รูปของข้อมูล | record ของ Cop ที่ตายตัว | แถวอิสระจาก `output` |
| เหมาะกับ | ระบบที่ Cop รู้จักงานอยู่แล้ว | ระบบใหม่ที่ Cop ยังไม่มี tool |

ถ้าระบบตรงกับ port ที่มีอยู่ ใช้ port ก่อน ผู้ใช้จะได้การ์ดและกติกาเดิม และสิทธิ์เรื่องคนถูกตรวจด้วยสายบังคับบัญชาจาก `directory`
