## Adapter

```ts
function factRowOf(request: FactRequest, record: Record<string, unknown>): FactRow {
  const dims = Object.fromEntries(request.dims.map((dim) => [dim, String(record[dim])]));
  return { dims, value: Number(record.value), weight: Number(record.weight ?? 1) };
}

async function readOne(request: FactRequest): Promise<FactResult> {
  const { sql, binds } = sqlFor(request);
  try {
    return { ok: true, rows: (await snowflakeQuery(sql, binds)).map((record) => factRowOf(request, record)) };
  } catch (error) {
    return { ok: false, code: "BAD_QUERY", error: error instanceof Error ? error.message : String(error) };
  }
}

export const snowflakeMetrics: MetricsPort = {
  ...GENERATOR_PORTS.metrics,
  readFacts: (requests) => Promise.all(requests.map(readOne)),
};
```

`...GENERATOR_PORTS.metrics` ทำให้เปลี่ยนทีละส่วนได้ เริ่มจาก `readFacts` ก่อน แล้วค่อยแทน `masterData`, `listMetrics` และ `describeEntity`

## `sqlFor` ทำอะไร

ผู้จัดการขายภาคอีสานถาม "ยอดขายเข้าเดือนนี้เทียบเดือนก่อน แยกตามเอเย่นต์" Winyu ส่งคำขอสองชุด

```ts
{ metric: "net_sales_volume", measure: "actual", dims: ["agent"],
  filters: { region: ["northeast"] }, range: { from: "2026-09-01", to: "2026-09-25" },
  labelShift: { days: 0, months: 0 } }

{ metric: "net_sales_volume", measure: "actual", dims: ["agent"],
  filters: { region: ["northeast"] }, range: { from: "2026-08-01", to: "2026-08-25" },
  labelShift: { days: 0, months: 1 } }
```

`sqlFor` แปลงแต่ละชุดเป็น SQL ที่มีรูปเดียวกันเสมอ

```sql
SELECT agent_id AS agent, SUM(volume_l) AS value, 1 AS weight
FROM sales.fact_sell_in
WHERE sale_date BETWEEN ? AND ?
  AND region_id IN (?)
GROUP BY agent_id
```

- ชื่อตาราง คอลัมน์ และนิพจน์ของแต่ละ metric มาจาก mapping ที่เขียนไว้ใน adapter ค่าจากคำขอ (`range`, `filters`) ส่งเป็น bind parameter ทุกครั้ง
- `filters` มีขอบเขตของผู้ถามรวมอยู่แล้ว (`region: ["northeast"]`) adapter ใส่ทุกตัวกรองลงใน `WHERE` โดยไม่ต้องรู้เรื่องสิทธิ์
- ถ้ามิติเป็นเวลา (`date`, `week`, `month`) ให้เลื่อนป้ายตาม `labelShift` เช่น `DATEADD(month, 1, DATE_TRUNC(month, sale_date)) AS month` แถวของเดือนก่อนจึงจับคู่กับเดือนนี้ได้
- `measure: "target"` อ่านจากตารางเป้าแทนตารางยอดจริง
- metric ที่เป็นอัตราส่วน คืน `value` เป็นอัตราส่วนของกลุ่ม และ `weight` เป็นตัวหาร เช่น การบรรลุเป้าคืน `SUM(actual) * 100 / SUM(target) AS value, SUM(target) AS weight`

## ติดตั้ง

แก้ค่าเริ่มต้นใน `lib/server/ports/index.ts`

```ts
let current: Ports = { ...GENERATOR_PORTS, metrics: snowflakeMetrics };
```

`registerPorts` มีไว้สำหรับเทสต์ ค่าในหน่วยความจำของ Next.js ไม่ข้าม route จึงไม่ควรใช้ติดตั้งตอนเริ่ม server

## ตรวจว่าตัวเลขตรง

ก่อนเปิดใช้ ให้รันคำถามชุดเดียวกันกับรายงานเดิมของทีมข้อมูล (ยอดรายภาค รายเดือน เทียบเป้า) และเทียบตัวเลขทีละช่อง ถ้าไม่ตรง ปัญหามักอยู่ที่ mapping ของ metric หรือการเลื่อนป้ายเวลา ไม่ใช่ที่ Winyu
