## รหัสใน path

```ts
const BALANCE_BODY = z.object({
  data: z.object({
    employee_id: z.string(),
    region: z.string(),
    items: z.array(z.object({ kind: z.string(), left_days: z.number() })),
  }),
});

function leaveBalanceOutput(body: unknown): ConnectorOutput {
  const { data } = BALANCE_BODY.parse(body);
  return { rows: data.items.map((item) => ({ employee_id: data.employee_id, region: data.region, kind: item.kind, left_days: item.left_days })) };
}

leave_balance: {
  method: "GET",
  path: "/employees/{employeeId}/leave-balance",
  labelTh: "ดูวันลาคงเหลือ",
  description: "Leave days left per kind for one employee. employeeId is required (an id such as e_1042). Call it for วันลาเหลือกี่วัน questions.",
  tier: "read",
  roles: "all",
  input: z.object({ employeeId: z.string(), year: z.number().nullable() }),
  output: leaveBalanceOutput,
  scope: [{ kind: "filter", rows: onlyOwnRegions }],
},
```

AI เรียก `{ employeeId: "e_1042", year: 2026 }` Cop ส่ง

```http
GET /api/employees/e_1042/leave-balance?year=2026
```

- `{employeeId}` ถูกเติมจาก argument ชื่อเดียวกันและ encode แล้ว ถ้า input ไม่มี argument ชื่อนี้ server ไม่ยอมเริ่ม
- `year` ไม่อยู่ใน path จึงเป็น query string ถ้าเป็น `null` จะไม่ถูกส่ง
- `output` แปลงผลแบบซ้อน (`data.items`) เป็นแถวแบน แถวละหนึ่งประเภทการลา AI อ่านง่ายกว่าและ `filter` ตรวจ `region` ได้

## รายงานที่ขอด้วย POST

```ts
salary_history: {
  method: "POST",
  path: "/reports/salary-history",
  labelTh: "ดูประวัติเงินเดือน",
  description: "Salary changes of one department in a year, one row per person and change.",
  tier: "read",
  roles: ["ceo", "hr_manager", "sales_director", "sales_rsm"],
  input: z.object({ department: z.string(), year: z.number(), regions: z.string().nullable() }),
  output: (body) => ({ rows: z.object({ rows: z.array(z.record(z.string(), z.unknown())) }).parse(body).rows }),
  scope: [
    { kind: "inject", args: (access) => ({ regions: access.regions === "all" ? null : access.regions.join(",") }) },
    { kind: "filter", rows: onlyOwnRegions },
  ],
  sensitive: [
    { field: "salary", labelTh: "เงินเดือนรายคน", full: ["ceo", "hr_manager"], masked: ["sales_director", "sales_rsm"] },
    { field: "national_id", labelTh: "เลขบัตรประชาชน", full: ["hr_manager"] },
  ],
},
```

ผู้จัดการขายภาคอีสานถาม แม้ AI ส่ง `regions: "all"` Cop ก็ส่ง

```http
POST /api/reports/salary-history
content-type: application/json

{"department":"ขาย","year":2026,"regions":"northeast"}
```

`method: "POST"` ใช้ได้กับ `tier: "read"` เมื่อ API ใช้ POST เพียงเพราะตัวกรองยาว ถ้า endpoint เปลี่ยนข้อมูลในระบบต้นทาง ต้องเป็น `write` ดู[เครื่องมือที่ต้องอนุมัติ](/docs/connect/examples/write-approval)
