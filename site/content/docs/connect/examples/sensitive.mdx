## Config

```ts
sensitive: [
  { field: "salary", labelTh: "เงินเดือนรายคน", full: ["ceo", "hr_manager"], masked: ["sales_director", "sales_rsm"] },
  { field: "national_id", labelTh: "เลขบัตรประชาชน", full: ["hr_manager"] },
],
```

## สามระดับ

| ระดับ | บทบาท | แถวที่ได้ |
|---|---|---|
| เห็นเต็ม | อยู่ใน `full` | `{ "salary": 52000 }` |
| เห็นเป็น `***` | อยู่ใน `masked` | `{ "salary": "***" }` รู้ว่ามีค่า แต่ไม่เห็นตัวเลข |
| ไม่เห็น | ไม่อยู่ในทั้งสองรายการ | ไม่มีคีย์ `salary` ในแถว |

- ฟิลด์ที่ลงท้าย `_label` ของฟิลด์เดียวกัน เช่น `salary_label` ถูกปิดไปพร้อมกัน
- บทบาทที่ไม่ได้ระบุไม่เห็นเลย ค่าเริ่มต้นจึงเป็นการปิด
- `provenance.masked` ของผลลัพธ์บอกชื่อฟิลด์ที่ไม่ได้แสดงเต็ม AI จึงบอกผู้ใช้ได้ว่า "มี 1 ฟิลด์ถูกปิดตามสิทธิ์"
- audit บันทึกการเรียกนั้นเป็น `masked`

## ปรับในหน้า admin

ฟิลด์ที่ประกาศใน `sensitive` ขึ้นในแท็บสิทธิ์ตามบทบาท หมวด "ค่าจากระบบที่เชื่อมต่อ" ทันที admin เลือก Full, Masked หรือ None ต่อบทบาทได้โดยไม่ต้องแก้โค้ด การปรับมีผลกับคำถามถัดไป และหน้าภาพรวมบอกว่าใครเปลี่ยนอะไรจากค่าใน config
