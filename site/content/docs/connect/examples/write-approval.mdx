## Config

```ts
export const itsmConnector = defineRestConnector({
  id: "itsm",
  labelTh: "ระบบแจ้งซ่อม IT",
  sourceSystemTh: "ITSM",
  baseUrl: env.ITSM_URL,
  auth: (access) => ({ authorization: `Bearer ${cachedOboToken(access?.userId ?? "cop")}` }),
  timeoutMs: 6000,
  tools: {
    open_ticket: {
      method: "POST",
      path: "/tickets",
      labelTh: "เปิดใบแจ้งซ่อม",
      description: "Opens one IT ticket for the asking user. title and detail in Thai. Use it when the user asks to แจ้งซ่อม / เปิด ticket.",
      tier: "write",
      roles: "all",
      input: z.object({ title: z.string().min(1), detail: z.string(), requester: z.string().nullable() }),
      output: (body) => {
        const ticket = z.object({ id: z.string(), status: z.string() }).parse(body);
        return { summary: `เปิดใบแจ้งซ่อม ${ticket.id} แล้ว`, rows: [ticket] };
      },
      scope: [{ kind: "inject", args: (access) => ({ requester: access.userId }) }],
    },
  },
});
```

## สิ่งที่เกิดขึ้น

1. ผู้ใช้พิมพ์ "แจ้งซ่อมเครื่องพิมพ์ชั้น 3 เปิดไม่ติด"
2. AI เรียก `itsm__open_ticket` Cop หยุดไว้และแสดงการ์ดอนุมัติ ยังไม่มีคำขอไปที่ ITSM
3. ผู้ใช้กดอนุมัติ Cop เขียนทับ `requester` ด้วยรหัสของผู้ถาม แล้วส่ง `POST /tickets`
4. `summary` จาก `output` กลายเป็นข้อความยืนยัน audit บันทึกการเรียกพร้อม argument ย่อ

`requester` มาจาก `inject` เสมอ AI จึงเปิดใบแจ้งซ่อมในนามคนอื่นไม่ได้ ค่านี้ใส่ตอนส่งคำขอหลังอนุมัติ การ์ดจึงแสดงเฉพาะ argument ที่ AI ส่งมา

## ระดับของ tool

| `tier` | ก่อนเรียก | ใครใช้ได้ |
|---|---|---|
| `read` | เรียกทันที | บทบาทใน `roles` และบทบาทที่ admin เพิ่มให้ |
| `write` | การ์ดอนุมัติ | บทบาทใน `roles` และบทบาทที่ admin เพิ่มให้ |
| `destructive` | การ์ดอนุมัติ | เฉพาะบทบาทใน `roles` admin ถอดได้แต่ให้บทบาทอื่นเพิ่มไม่ได้ |

ถ้าไม่ระบุ `tier` Cop ถือเป็น `destructive` tool ที่ลืมระบุจึงปลอดภัยไว้ก่อน

## การ์ดอนุมัติ

tool จาก connector ใช้การ์ดมาตรฐาน ซึ่งถามว่า "อนุมัติให้ใช้ itsm__open_ticket ไหม" และแสดง argument ทีละบรรทัด ถ้าต้องการการ์ดที่บอกผลของการกดเป็นภาษาคน เช่น "เปิดใบแจ้งซ่อมให้คุณ · เครื่องพิมพ์ชั้น 3" ให้เพิ่มกรณีของ tool นั้นใน `components/cards/describe-tool.ts` (ข้อความ) และ `components/cards/approval-card.tsx` (การ์ด)
