## สัญญา

ทุกที่ใน Cop ที่ต้องการตัวเลข ทั้งแดชบอร์ด แชท การแจ้งเตือน และสรุปตอนเช้า อ่านผ่าน port เดียวนี้

```ts
export type MetricsPort = {
  readFacts(requests: FactRequest[]): Promise<FactResult[]>;
  masterData(): Promise<MasterData>;
  listMetrics(search: string | null): Promise<MetricDef[]>;
  describeEntity(kind: EntityKind, query: string): Promise<EntityDescription>;
};
```

คลังข้อมูลไม่รู้ว่าใครถาม Cop ตรวจ query กับนิยาม metric ใส่ขอบเขตของผู้ถาม และแตกคำถามหนึ่งข้อเป็นคำขอรวมยอดก่อน แล้วส่งให้ adapter เฉพาะคำขอที่ตัดขอบเขตแล้ว

```ts
export type FactRequest = {
  metric: MetricId;
  measure: "actual" | "target";
  dims: Dim[];
  filters: Partial<Record<Dim, string[]>>;
  range: { from: string; to: string };
  labelShift: { days: number; months: number };
};

export type FactRow = { dims: Partial<Record<Dim, string>>; value: number; weight: number };
export type FactResult = { ok: true; rows: FactRow[] } | { ok: false; code: "BAD_QUERY"; error: string };
```

- `filters` มีขอบเขตของผู้ถามรวมอยู่แล้ว adapter กรองตามนี้ทุกค่า ไม่ต้องรู้เรื่องสิทธิ์
- `measure: "target"` คือขอเป้า ไม่ใช่ยอดจริง ใช้เมื่อผู้ใช้เทียบกับเป้า
- `labelShift` ใช้กับคำขอของงวดก่อน ให้เลื่อนป้ายเวลา (`date`, `week`, `month`) ไปข้างหน้าตามจำนวนนี้ แถวของงวดก่อนจึงมี key ตรงกับงวดปัจจุบันที่ถูกเทียบ
- metric ที่เป็นอัตราส่วน เช่น การบรรลุเป้าหรือวันครอบคลุมสต๊อก คืน `value` เป็นอัตราส่วนของกลุ่มนั้น และ `weight` เป็นตัวหาร Cop รวมต่อด้วยค่าเฉลี่ยถ่วงน้ำหนัก metric อื่นคืน `weight: 1`
- `masterData()` คืนรายชื่อภาค จังหวัด เอเย่นต์ แบรนด์ SKU ดีซี โรงงาน และแคมเปญ Cop ใช้ตรวจสิทธิ์ (เอเย่นต์นี้อยู่ภาคไหน) และแสดงชื่อภาษาไทย และ cache ไว้ตามรอบของข้อมูล

การเปลี่ยนไปใช้คลังข้อมูลจริงคือเขียน adapter ที่ทำตามสัญญานี้ ดู[ตัวอย่าง adapter ของคลังข้อมูล](/docs/connect/examples/warehouse) หน้าจอ แชท และ logic อื่นไม่ต้องแก้

## อะไรอยู่ใน adapter อะไรอยู่ใน Cop

| อยู่ใน Cop (ไม่เปลี่ยน) | อยู่ใน adapter |
|---|---|
| ตรวจ query กับนิยาม metric | แปลง `FactRequest` เป็น SQL หรือคำขอไปยัง semantic layer |
| ใส่ขอบเขตภาคและแบรนด์ลงใน `filters` | ส่งคำขอด้วยบัญชีที่ได้รับอนุญาต |
| ซ่อนกลุ่มที่เล็กเกินไป (small-cell) | แปลงผลกลับเป็น `FactRow` |
| คำนวณช่วงเปรียบเทียบ จัดเรียง ตัดแถว | อ่าน master data |
| headline, summary, provenance | |

## ต่อผ่าน semantic layer ที่มีอยู่

ถ้าองค์กรมี semantic layer ที่รับรองแล้ว ให้ adapter อ่านผ่านตัวนั้น ตัวเลขใน Cop จะตรงกับรายงานเดิมโดยอัตโนมัติ และนิยาม metric ไม่ต้องเขียนซ้ำ

<Tabs items={["Snowflake Semantic View", "SQL ตรง", "dbt / Cube"]}>
<Tab value="Snowflake Semantic View">

นิยามตาราง ความสัมพันธ์ มิติ และ metric ไว้ใน Snowflake แล้วขอเฉพาะ metric กับมิติที่ต้องการ

```sql
SELECT * FROM SEMANTIC_VIEW(
  sales_sv
  METRICS net_sales_volume
  DIMENSIONS region, month
  WHERE region IN ('north', 'northeast')
);
```

ขอบเขตภาคใน `WHERE` มาจาก Cop เสมอ ไม่ได้มาจาก AI

</Tab>
<Tab value="SQL ตรง">

ถ้ายังไม่มี semantic layer ให้ทำ view ร่วมกับทีมข้อมูล แล้ว map แต่ละ metric กับนิพจน์และคอลัมน์วันที่ และแต่ละมิติกับคอลัมน์และ join ที่ใช้ ค่าจากผู้ใช้ส่งเป็น bind parameter ทุกครั้ง ชื่อคอลัมน์มาจาก mapping เท่านั้น

metric ที่เป็นอัตราส่วน เช่น การบรรลุเป้าหรือวันครอบคลุมสต๊อก ต้องส่งตัวตั้งและตัวหารกลับมาแยกกัน ให้ Cop เป็นผู้หาร ถ้าหารใน SQL แล้วรวมต่อ ค่าจะผิด

</Tab>
<Tab value="dbt / Cube">

ใช้ API ของ semantic layer ที่มีอยู่ (dbt Semantic Layer, Cube REST) โดยส่ง metric มิติ ช่วงเวลา และตัวกรองขอบเขต adapter แปลงผลเป็นแถวของ Cop

</Tab>
</Tabs>

## ช่องทางรับส่ง

ประตูตัวเลขไม่ผูกกับช่องทาง adapter จะเรียกคลังข้อมูลด้วย driver, REST (เช่น Snowflake SQL API) หรือ MCP ก็ได้ ถ้าคลังข้อมูลมี MCP server ให้เรียก tool ของมันจากใน adapter อย่าเปิด tool "รัน SQL" ให้ AI เรียกเองในแชท เพราะ AI จะเขียน SQL ข้ามขอบเขตได้ และตัวเลขจะไม่ผ่านนิยาม metric ชุดเดียวกับการ์ด

## สิ่งที่ต้องเตรียมเพิ่ม

- **Cache**: การเปิดแดชบอร์ดหนึ่งครั้งส่ง query เท่าจำนวนการ์ด ควร cache ผลตาม query และขอบเขต โดยตั้งอายุตามรอบอัปเดตของข้อมูล
- **Timeout**: ถ้าคลังข้อมูลไม่ตอบ การ์ดใบนั้นแสดงว่าไม่มีข้อมูลในขณะนี้ ส่วนอื่นของหน้ายังใช้งานได้
- **การแจ้งเตือนและพยากรณ์**: ย้ายไปอ่านผ่าน port เดียวกัน หรือให้คลังข้อมูลคำนวณเป็น batch แล้ว Cop อ่านผลไปใช้
